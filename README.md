 e-plantShopping 🌱

## 📌 Project Overview
**e-plantShopping** is a simple and interactive e-commerce web application built for browsing and shopping plants online. The project allows users to explore different plant categories, view plant details, and simulate adding items to a shopping cart.

This application is built to practice modern front-end development concepts such as component-based architecture, state management, and dynamic rendering.

## 🚀 Features
- Browse plants by categories
- View detailed plant information
- Add plants to shopping cart
- Dynamic rendering using React components
- Clean and responsive UI design


## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
